Termux TEWL

A terminal-style fictional database demonstration for Termux.

Features

• Fast terminal record stream
• Interactive menu
• Sample record review
• Colorful terminal interface
• No external Python dependencies

Installation

Install Git and Python:

bash
pkg update
pkg install git python


Clone the repository:

bash
git clone https://github.com/maker141/termux-tewl.git
cd termux-tewl


Run the program:

bash
python main.py


Menu

1. Start record stream
2. Review sample records
3. Stop and exit

Disclaimer

This program generates fictional sample records.
It does not connect to FBI systems or access real records.
